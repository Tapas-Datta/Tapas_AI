# ✳ TD_AI — AI-Powered Multilingual Chat Assistant

**Your Personal AI Conversation Experience.**

TD_AI is a multilingual AI-powered chat application built with **Node.js and Groq API**, designed to make artificial intelligence accessible through a clean, modern, and responsive interface.

The platform enables users to interact with AI naturally, receive multilingual responses, and maintain their conversation history through a simple browser-based experience.

---

## ✨ Key Features

- 🤖 **AI-Powered Conversations** — Interact with an AI assistant in real time.
- 🌍 **Multilingual Support** — Communicate in multiple languages.
- 💬 **Chat History** — Keep track of previous conversations using browser storage.
- 🎨 **Modern UI** — Enjoy a clean and intuitive chat interface.
- 📱 **Responsive Design** — Access the application across different screen sizes.
- 🔐 **Secure API Integration** — Handle Groq API requests through server-side integration.
- ⚡ **Fast AI Responses** — Powered by Groq's AI inference infrastructure.

## ⚙️ Getting Started

Follow these steps to run TD_AI locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Tapas-Datta/Tapas_AI.git
```

### 2. Navigate to the Project Directory

```bash
cd Tapas_AI
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory:

```env
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=openai/gpt-oss-20b
PORT=3000
```

**Important:** Replace `your_groq_api_key` with your actual Groq API key.

Never upload your `.env` file or expose your API key publicly on GitHub.

### 5. Start the Application

```bash
npm start
```

Open your browser and visit:

```text
http://localhost:3000
```

You're ready to start chatting with TD_AI! 🚀

## 🚀 Deployment

TD_AI supports deployment through platforms such as:

- **Vercel**
- **Render**

To deploy:

1. Connect your GitHub repository to your deployment platform.
2. Configure the required environment variables.
3. Add your `GROQ_API_KEY`.
4. Set your `GROQ_MODEL` if required.
5. Deploy your application.

**Note:** Ensure your hosting platform supports your Node.js server setup and start command.

## 🔐 Security

Security is an important part of TD_AI.

- API keys are managed through environment variables.
- AI requests are handled through server-side API integration.
- Sensitive credentials should never be committed to GitHub.
- Keep your `.env` file excluded through `.gitignore`.
